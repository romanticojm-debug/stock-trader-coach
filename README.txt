# BTC 15M App V2

Aplicación web de análisis educativo para BTC/USDT.

## Cómo abrir
1. Descomprime `btc-15m-app-v2.zip`.
2. Abre `index.html` en un navegador moderno.
3. Mantén la conexión a internet activa.
4. Si tu navegador bloquea conexiones al abrir archivos locales, usa el alojamiento estático de GitHub Pages o un servidor local.

## Incluye
- Precio y velas BTC/USDT de 15 minutos desde endpoints públicos de Binance.
- Actualización mediante WebSocket.
- Indicadores EMA 9, EMA 21 y RSI 14.
- Señal educativa BUY / WAIT / SELL con reglas transparentes.
- Stop-loss y objetivo orientativos basados en ATR aproximado.
- Alertas de navegador si están permitidas.

## Importante
- No ejecuta operaciones ni envía órdenes.
- No garantiza resultados ni es asesoramiento financiero.
- Los datos pueden desconectarse o retrasarse. Verifica siempre los precios y riesgos.
- No requiere API key ni credenciales.
